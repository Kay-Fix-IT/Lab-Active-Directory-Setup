# Kays Enterprise Server Configuration File

## Overview
* This server functions as the primary domain controller for the lab network. It manages authentication, Directory services and name resolution for the environment.

## System Specifications
* **OS:** Windows Server 2022
* **Hostname:** WIN-2L2INDLOH1I
* **IP address:** 192.168.0.1
* **Subnet Mask:** 255.255.255.0
* **Default Gateway:** 192.168.0.1

##Core services
* **Active Directory Domain Services (AD DS):** Deployed and configured to manage local identity
* **DNS** Configured for forward and reverse lookups within the domain
* **Network:** Kintnet
